# AKF_GAM207_ArenaPrototype

A fast-paced arena shooter prototype developed in Unreal Engine 5 as
part of the GAM 207: Information Technology and Digital Games course at
Southern New Hampshire University.

This project focuses on implementing core gameplay systems and exploring
iterative design within a scoped prototype.

------------------------------------------------------------------------

## Project Overview

This prototype was created as a final course project and showcases
foundational gameplay systems built in Unreal Engine using Blueprint
scripting. The emphasis is on mechanics, interaction, and system
integration rather than visual polish.

Key systems implemented include:

-   Player character with third-person movement and projectile-based
    combat
-   Enemy AI using Behavior Trees and Blackboards for navigation,
    combat, and decision-making
-   Persistent shield resource system integrated into the damage
    pipeline
-   AI decision-making for seeking health and shield pickups based on
    current resource levels
-   Updated HUD displaying player health, shield, ammo, and gameplay
    feedback
-   Interactive health and shield pickups supporting the core gameplay
    loop
-   Improved arena layout, lighting, and overall gameplay polish

This project demonstrates an understanding of Unreal Engine workflows,
gameplay logic, and iterative system development.

## How to Run

1.  Open the `.uproject` file in Unreal Engine 5.
2.  Launch the project in-editor using the Play button.
3.  Use standard WASD and mouse controls to move and interact.

This project is intended to be run within the Unreal Editor. No packaged
build is included.
